# SushiWave — курсова робота, варіант 11

Навчальний вебзастосунок замовлення суші та ролів. **Справжніх замовлень і платежів немає.**

## Запуск (Windows / PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

У браузері відкрийте `http://127.0.0.1:5000`.

База `sushiwave.db` створюється автоматично під час першого запуску, з тестовим меню (26 страв), додатками та обліковим записом оператора.

## Локальний вхід оператора

Адреса: `http://127.0.0.1:5000/operator/login`

Тестовий логін: `operator`
Тестовий пароль: `DemoSushi2026!`

Це **лише локальні демонстраційні дані**. Не публікуйте проєкт у мережі з тестовими обліковими даними або типовим SECRET_KEY. Для нового сховища задайте змінні середовища `ADMIN_USER`, `ADMIN_PASSWORD`, `SECRET_KEY` перед першим запуском.

## Сценарії для скриншотів

1. VS Code — дерево каталогу (не показуйте `.venv` повністю).
2. Термінал — адреса після запуску Flask.
3. `/` — головний екран.
4. `/#menu` — меню з 26 позицій у 5 категоріях.
5. Пошук «Філадельфія».
6. Картка продукту і вибір додатків.
7. Кошик із двома позиціями.
8. Форма оформлення з коректним часом отримання.
9. Сторінка підтвердження та відстеження `/track/<token>`.
10. Панель оператора `/operator` зі списком тестових замовлень.
11. Статус після зміни оператором.
12. Каталог адміністратора `/operator/products` із вимкненою стравою.
13. Помилка замовлення через недоступний продукт.
14. Помилка валідації некоректного часу.
15. Відмова неавторизованому користувачу при спробі доступу до `/operator`.
16. Тести в терміналі.
17. Адаптивний режим у Chrome DevTools (360px та 768px).
18. ER-діаграма БД — створити окремо, не фотографувати редактор.

.\.venv\Scripts\python.exe -m unittest discover -s tests -v

## Модель даних

- `categories` 1→N `products`
- `orders` 1→N `order_items` N→1 `products`
- `order_items` 1→N `item_modifiers`
- `orders` 1→N `status_history`
- `operators` — доступ до панелі оператора
- `modifiers` — каталог можливих додатків

## Обмеження

- Це навчальна модель **самовивозу**, без оплати карткою чи доставки.
- Під час створення замовлення сервер заново визначає ціну кожної позиції та додатків.
- Поля телефону і коментаря не відображаються в загальнодоступному каталозі.
- Посилання на відстеження містить випадковий секретний токен; його не можна поширювати.
- Для реального розгортання необхідні додаткові заходи: налаштування HTTPS, секретів, обмеження частоти спроб входу та обробка персональних даних.
